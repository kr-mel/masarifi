# Masarifi (مصاريفي)

Offline-first Arabic (RTL) expense tracker, installable as a PWA. All data stays on the device (localStorage).

**Live:** https://kr-mel.github.io/masarifi/

## Features
- Add expenses by category, set monthly budgets, track savings
- Charts, spending insights and a financial health score
- Export to CSV, JSON, PDF and text
- Light/dark themes, Arabic and English, works offline (service worker)

## Tech
JavaScript, React (no JSX), service worker, web manifest, Cloudflare Worker for optional sign-in. Money is stored as integer cents.
